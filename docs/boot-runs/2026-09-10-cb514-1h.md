## Machine

Identified by class, never by serial number — the class is what somebody reproducing this run has to
match, and the serial identifies a physical object that warranty lookups map back to a purchase.

- Make and model: Acer Chromebook 514, `CB514-1H-C0FF` (Acer model number `N18Q3`)
- Platform: Intel Apollo Lake
- Manufactured: 2020-10
- Firmware: coreboot with the `RW_LEGACY` SeaBIOS payload; **developer mode enabled**
- Firmware path booted: **BIOS**. This machine has no UEFI path without flashing a full ROM, so
  `build/grub.cfg` and `efifb` are unreachable from here and `I-7` records `vesafb` at `vga=791`
- Secure Boot / verified boot: **not applicable as usually asked.** Stock coreboot will not boot a
  foreign USB medium at all; the firmware was not configured but bypassed, by enabling developer
  mode and its legacy payload. v0.1 does not support Secure Boot on any host — `build/grub.cfg`
  requires the setting off even on the UEFI path
- Camera: **built-in lid webcam.** Internally a USB UVC device, so unlike the keyboard it *is* on
  the bus `uvcvideo` and `authorized_default=0` govern — `I-6` records the driver and `S-6` the
  framing aid. No external camera is needed on this machine
- Keyboard: **built-in.** Bound through the kernel image's own i8042/atkbd path, not through
  `usbhid`; `I-8` records what `/proc/bus/input/devices` shows
- Watch-only wallet: Sparrow, `<version>`, on `<machine>`
